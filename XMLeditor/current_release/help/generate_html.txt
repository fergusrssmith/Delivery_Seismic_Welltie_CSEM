other_html/introduction.html
Introduction to the XML Editor
This XML Editor was designed for the purpose of creating and editing files based on an XML Schema.  It's default features include selecting a schema, opening new files and creating existing ones, viewing and editing those files, and copy and paste functionality between files.  In addition, there may be other plugins which add additional functionality.</p><p>Usage:</p><p> script.sh [options]</p><p>where</p><p>script.sh = some script file which calls .../java ... model.DEditor</p><p> options = command line options as defined below:</p><p> * xsd=filename, where filename is the name of the XML Schema to load</p><p> * xml=filename, where filename is the name of an XML file to open</p><p> * cfg=filename, where filename is the name of a customiation / configuration file</p><p> * -S disables ability to load schema (other than with command line xsd=filename)</p><p> * -X disables ability to load XML file (other than with command line xml=filename)</p><p> * -N disables ability to make a new file from scratch</p><p> * -V enables lax checking (faster speed, but not error proof)</p><p>Requirements:</p><p> Java version 1.4.0 or higher (you might get it to work with 1.3 plus the JAXP and regex libraries, but I make no guarantees)</p><p> JavaHelp version 1.1 or higher</p><p> Sun Multi Schema XML Validator package (msv) and supporting libraries:  msv.jar, isorelax.jar, relaxngDatatype.jar, xsdlib.jar</p><p> To be able to get default values and / or run as an applet, you will need my modified version of msv.jar</p><p>Customization XML File:</p><p> The top layer should be <config_options>.  Inside that are <tree_display> and <edit_dialog>.  Inside each are any number of <customization> tags with children <name>, <value>, and <effect>.  <tree_display> sub elements are used to create RenderInfo classes for rendering the tree.  <edit_dialog> sub elements are used to customize the dialog produced by choosing "Edit Tag" or double clicking on a node in the tree.  Below is a brief explanation of how the tags work.  </p><p><effect>'s are displayed when a node in the tree has the attribute inside of a<customization>'s <name> with the value equalling that in <value>.  For instance, for the following customization, </p><p><customization></p><p> <name>day</name></p><p> <value>Wednesday</value></p><p> <effect>someEffect</effect></p><p></customization></p><p>when some element is of the form <element_name day="Wednesday">...</elementname> then someEffect is put into place.</p><p>tree_display effect meaning: A.B.C.D.E.F</p><p> A = what to display (can be a combination): n = node name, d = display name (include subchildren values if their name is "name"), a = attributes, v = node value</p><p> B = font style: 0 = plain, 1 = bold, 2 = italics, 3 = bold and italic </p><p> C = red value: 0 (no red) to 255 (bright red)</p><p> D = green value: 0 (no green) to 255 (bright green)</p><p> E = blue value: 0 (no blue) to 255 (bright blue)</p><p> F = alpha value: 0 (fully transparent) to 255 (totally opaque)</p><p>edit dialog effect meaning</p><p> starts with "Xcm:" ("X- custom message:"): following text displayed with or overlaps existing message depending on X:</p><p> 'r' - replace</p><p> 'p' - prepend</p><p>'a' - append</p><p>"ne": value in edit box is non-editable when effect is on (use "ne+X") to combine "ne" with other options</p><p>starts with "rvm:": replace the value with a message

filemenu/new_xml.html
Making a new XML file
Creating a new XML file with default values is as simple as clicking the mouse.  Simple choose the button with the new icon <img src="../../icons/new_xml.jpg"> or choose "New" from the "File" menu.  A new window will open with an XML file generated to have the default content and values given the current XML Schema.  A Schema is either loaded at run time or through the "File" menu.

filemenu/open_xml.html
Opening an XML file
Simply choose "Open XML..." from the "File" menu or click on the open icon <img src="../../icons/open_xml.jpg"> button to pop up a dialog to choose an XML file to open.  The XML file will then open in a new window and be automatically validated against the Schema.

filemenu/save_xml.html
Saving an XML file
Choosing "Save" from the "File" menu or clicking on the save icon <img src="../../icons/save_xml.jpg"> will save the currently selected XML file.  If the file has not been saved previously, those actions are equivalent to "Save As..." from the "File" menu and will result in a dialog popping up asking the user to specify a location to save the currently selected XML file.

editmenu/insert_above.html
Insert Above
The "Insert Above" function inserts a new subtree (which may be just a leaf or a tree with many layers beneath it) immediately above / before the currently selected subtree in the XML tree.  It is activated in the "Edit" menu or by the button <img src="../../icons/insert_before.jpg">.  It presents the user with all legal options for inserting above / before.  All subtrees created are filled with default child nodes and values to maintain validity of the XML with respect to the Schema.

editmenu/insert_child.html 
Insert As Sub-Item
The "Insert As Sub-Item" function inserts a new subtree (which may be just a leaf or a tree with many layers beneath it) as a child of the currently selected subtree in the XML tree.  It is activated in the "Edit" menu or by the button <img src="../../icons/insert_child.jpg">.  It presents the user with all legal options for inserting child elements.  All subtrees created are filled with default child nodes and values to maintain validity of the XML with respect to the Schema.

editmenu/insert_below.html
Insert Below
The "Insert Below" function inserts a new subtree (which may be just a leaf or a tree with many layers beneath it) immediately below / after the currently selected subtree in the XML tree.  It is activated in the "Edit" menu or by the button <img src="../../icons/insert_after.jpg">.  It presents the user with all legal options for inserting below / after.  All subtrees created are filled with default child nodes and values to maintain validity of the XML with respect to the Schema.

editmenu/switch.html
Switch
The "Switch" function changes the currently selected subtree into another subtree which would also be valid at its present location.  It is activated in the "Edit" menu or by the button <img src="../../icons/switch.jpg">.  The user is presented with a list of replacement choices.  Any subtree chosen will then replace the selected subtree with a new subtree with default values.  Note that this also applies if the same name is picked as the currently selected subtree, and it will be replaced with a default subtree with its name.

editmenu/edit_value.html
Edit Value
The "Edit Value" function pops up a dialog which allows the user to change the value or attributes of a node.  It is activated in the "Edit" menu,by the button <img src="../../icons/insert_child.jpg">, or by double-clicking on a node.  Under the default implementation (plugins can change the behavior) the dialog contains a table for attributes and a text field in which to edit the value, plus messages concerning constraints on the value.

editmenu/copy.html
Copy
The "Copy" function copies the currently selected (and contiguous) subtrees.  It is activated in the "Edit" menu or by the button <img src="../../icons/copy.jpg">.  They can then be pasted in appropriate locations in any opened XML file.

editmenu/cut.html
Cut
The "Cut" function removes the currently selected (and contiguous) subtrees and copies them.  It is activated in the "Edit" menu or by the button <img src="../../icons/cut.jpg">.  Note that this replaces whatever was previously copied.

editmenu/paste_above.html
Paste Above
The "Paste Above" function pastes the currently copied (and contiguous) subtrees immediately above / before the currently selected subtree, in the same order as they were in the location from which they were copied.  It is activated in the "Edit" menu or by the button <img src="../../icons/paste_before.jpg">.  

editmenu/paste_child.html
Paste As Sub-Item
The "Paste As Sub-Item" function pastes the currently copied (and contiguous) subtrees as a child of the currently selected subtree in whatever location the user selects among the list of valid places to paste.  It is activated in the "Edit" menu or by the button <img src="../../icons/paste_child.jpg">.  

editmenu/paste_below.html
Paste Below
The "Paste Below" function pastes the currently copied (and contiguous) subtrees immediately below / after the currently selected subtree, in the same order as they were in the location from which they were copied.  It is activated in the "Edit" menu or by the button <img src="../../icons/paste_after.jpg">.  

UIComponents/tree.html
The XML Tree
The XML Tree is the major work area for the program.  Right clicking in this window brings up the "Edit" menu which contains all the major options for tree manipulation -- insert, cut, copy, paste, edit, and switch.  Leaf nodes with values are show with their values beside them as per the instructions of the tree cell renderer being used.  By default, this means the value for leaf nodes and the values of any child named "name" and "value" for non-leaf nodes.  In Delivery mode certain attributes cause some of the text to become bold, italic, or hidden.  Other plugins may affect the text in different ways.

UIComponents/status.html
The Status Message
The status bar appears beneath the XML tree in the same window.  It keeps the user updated as to the validity status of the XML tree being edited.  If it becomes invalid (or more likely, an invalid XML file is loaded), the message should give the user some vague idea of where to start trying to fix it.

UIComponents/text.html
The XML Text Window
This window, which displays the text of an XML file being edited as a tree, appears when "Show XML Text" is chosen from the "Tools" Menu.  The text in this window is ineditable.  Hand editing, if necessary, must be done in a different editor.
