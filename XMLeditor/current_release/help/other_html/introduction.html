Introduction to the XML Editor

This XML Editor was designed for the purpose of creating and editing files based on an XML Schema. It's default features include selecting a schema, opening new files and creating existing ones, viewing and editing those files, and copy and paste functionality between files. In addition, there may be other plugins which add additional functionality.

Usage:

script.sh [options]

where

script.sh = some script file which calls .../java ... model.DEditor

options = command line options as defined below:

* xsd=filename, where filename is the name of the XML Schema to load

* xml=filename, where filename is the name of an XML file to open

* cfg=filename, where filename is the name of a customiation / configuration file

* -S disables ability to load schema (other than with command line xsd=filename)

* -X disables ability to load XML file (other than with command line xml=filename)

* -N disables ability to make a new file from scratch

* -V enables lax checking (faster speed, but not error proof)

Requirements:

Java version 1.4.0 or higher (you might get it to work with 1.3 plus the JAXP and regex libraries, but I make no guarantees)

JavaHelp version 1.1 or higher

Sun Multi Schema XML Validator package (msv) and supporting libraries: msv.jar, isorelax.jar, relaxngDatatype.jar, xsdlib.jar

To be able to get default values and / or run as an applet, you will need my modified version of msv.jar

tree_display effect meaning: A.B.C.D.E.F

A = what to display (can be a combination): n = node name, d = display name (include subchildren values if their name is "name"), a = attributes, v = node value

B = font style: 0 = plain, 1 = bold, 2 = italics, 3 = bold and italic

C = red value: 0 (no red) to 255 (bright red)

D = green value: 0 (no green) to 255 (bright green)

E = blue value: 0 (no blue) to 255 (bright blue)

F = alpha value: 0 (fully transparent) to 255 (totally opaque)
