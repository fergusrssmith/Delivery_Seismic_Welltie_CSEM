Rock and fluid properties

Information about the rocks and fluids in the system.
Usually, at least two rock types are needed (permeable and impermeable)

Fluid properties

A list of all the fluids that may appear in the problem, and their
characteristic properties:

name
 a sensible name that will be cross referenced in the model_description section (e.g. "40APIoil", "ref. brine")
vp
 p-wave velocity at in-situ conditions of this fluid
sigma_vp
 uncertainty in the vp (1 std. deviation). Set to zero if fluid well characterised
rho
 density at in-situ conditions of this fluid
sigma_rho
 uncertainty in density. Set to zero if fluid well characterised

Rock properties

A list of all the rocks that may appear in the problem, and their
characteristic properties. Rocks may be "reservoir" type (e.g. sands, chalks), or
"non-reservoir" (shales, mudstones etc).

name
 a sensible name that will be cross referenced in the model_description section (e.g. "main pay sand", "marineshale")
reference_fluid
 Appears only for reservoir rocks.
Name of fluid (see fluid properties) present in trend curves.
vp_curve
 Trend curve parameters for vp versus depth and LFIV (low freq. interval velocity), usually
a regression of form: vp = A.depth + B.LFIV + C. Make sure units are consistent. These
are typical numbers in ft/sec.......
Intercept:   C (e.g. 4320)
depth_coefficient: A (e.g. 0.33)
LFIV_coefficient: B (e.g. 0 if LFIV not used)
sigma: regression standard deviation (e.g. 250)
vs curve
 Trend curve parameters for shear velocity versus p-wave velocity:
vs versus vp, a regression of form: vs = A.vp + B. Make sure units are consistent. These
are typical numbers in ft/sec.......
Intercept:   B(e.g. -2930)
slope: A (e.g. 0.75)
sigma: regression standard deviation (e.g. 200)
porosity_curve
 Appears only for reservoir rocks.
Trend curve parameters for porosity versus p-wave velocity:
a regression of form: phi = A.vp + B. Make sure units are consistent. These
are typical numbers
Intercept:   B(e.g.  0.48)
slope: A (e.g. -0.00002)
sigma: regression standard deviation (e.g. 0.02)
density_curve
 Appears only for non-reservoir rocks.
Trend curve parameters for density versus p-wave velocity:
a Gardner-Gardner-Gregory regression of form: rho = factor.vpexponent.
Make sure units are consistent. These
are typical numbers
factor  (e.g.  0.22)
exponent: (e.g. 0.26)
sigma: (e.g. 0.02)
vp_grain
 Appears only for reservoir rocks.
p-wave velocity in pure grain material.
vs_grain
 Appears only for reservoir rocks.
shear  velocity in pure grain material.
rho_grain
 Appears only for reservoir rocks.
Density of pure grain material.
