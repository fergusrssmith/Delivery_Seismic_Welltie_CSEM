Model description

Information about the layers
At least 2 layers are required. Each layer has two end-member rocks (Net-to-gross may be trivially 1 or 0 though).

Making new layers
The attribute <synchronise_rock_matrix> should be checked only if
the layer above has the identical end-member rocks, and you want it to differ from the current layer only in the
effect of fluids. Only rarely will you want to do this kind of thing (e.g. for finding a contact in a thick reservoir).

Mandatory layer entries

Name
 layer name. Give layers a sensible, identifiable name.
reservoir_endmember
 details of permeable rock in layer. See below
nonreservoir_endmember
 details of impermeable rock in layer. See below
time
 prior mean time (ms) of layer top
sigma_time
 prior mean time uncertainty (standard deviation) (ms) of layer top. Usually something like 10ms.
net_to_gross
 prior mean net to gross of layer: 0<net_to_gross<1
depth
 prior mean depth of layer. You also may want to have this locked over a series of layers using the attribute same_as_layer_above. Must be in same units as rock trends regressions.
LFIV
 prior mean low-frequency-interval-velocity (LFIV) of layer (q.v. Rock trends). Put zero if no regression against LFIV is used.  If present, he LFIV is a large-scale quantity, so you may want to have this locked over a series of layers using the attribute same_as_layer_above. Must be in same units as rock trends regressions.
t_base
 Will only appear as mandatory entry on bottom layer. Same meaning as t, but for the bottom of the last layer.
sigma_t_base
 Will only appear as mandatory entry on bottom layer. Same meaning as sigma_t, but for the bottom of the last layer.


Optional layer entries

sigma_net_to_gross
 prior net-to-gross uncertainty (standard deviation) if uncertain. Typically 0.1-0.2. Set to zero if known, or omit entry.
sigma_depth
 prior depth uncertainty (standard deviation) if uncertain. Typically a few tens of feet.  Controls horizontal axis uncertainty in rock trends regressions, and often best set to zero if error bars in vp are significant. See also delivery docs on the --lock-depths option. Taken to be zero if entry omitted (often best choice)
sigma_LFIV
 uncertainty on LFIV (standard deviation) if uncertain. Taken to be zero if entry omitted.  The LFIV is a large-scale quantity, so you may want to have this locked using same_as_layer_above
thickness
 default prior constraint thickness on layer (isopach). Make sure units are consistent with velocities. Will usually vary_areally, so you may want to switch on this attribute if a thickness property is present in the input traces.
sigma_thickness
 uncertainty in layer thickness (perhaps a kriging standard deviation). Do not impose better than 1% of the layer thickness, even at wells (e.g. 1ft). Will usually vary_areally.


Important

Each one of these entries may have varies_areally turned on. If you do, make sure there is a suitable number coming in from the prior traces, you know which block it is, and you put a suitable entry in the property_indices section.


Rock entries

reservoir_endmember
 Required entries: name, and up to 4 kinds of fluids that may be present. At a minimum, you will have to enter a brine entry. Omit entries for oil, gas or lsg (low-sat-gas) if they can't be  in this layer (e.g. if you know it bears only water). The fluid names must correspond with the fluid names defined in the rock_fluid_properties section. The rock name must correspond to a rock defined in the  rock_fluid_properties section.
nonreservoir_endmember
 Required entries: name,  of an impermeable rock. The rock name must correspond to a rock defined in the  rock_fluid_properties section.
