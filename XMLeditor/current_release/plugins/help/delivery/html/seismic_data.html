Stack data

Information about the stack(s): Up to 2 stacks are allowed (use 2 if significant AVO effects possible).

Each stack must have sane entries for the

stackname :SU big--endian file containing the stack (may be a named pipe)

minimum offset (length units consistent with velocities e.g. ft, or m)

maximum offset (length units consistent with velocities e.g. ft or m)

reflector time to salient reflecor in model (milliseconds)

stack velocity (ft/second, or m/s)

Wavelet information

You must supply wavelet information.

wavelet filename: a big-endian SU file with one trace: the wavelet. Requisite header fields set correctly (ns,dt,f1).

Signal to noise. This is actually the estimated noise RMS amplitude. The wavelet extraction should yield this: it's unlikely to be smaller than about 20% of the signal size

AVO_terms

These are coefficients in the reflectivity model (see the tech. paper).
Usually A,B=1 and these are fixed (sigma_A=sigma_B=0, which is assumed if
there are no sigma_A/sigma_B entries). A,B, can be used to compensate for
amplitude errors in the wavelet if it's too small etc, but the wavelet extraction
ought really to have got this right, i.e. A=B=1.0.
