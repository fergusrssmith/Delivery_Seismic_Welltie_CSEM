Output

Some global flags that control output and the operating mode.

density_ordering
 Must be one of
none.  Any fluids are allowed in any permeable layer.
partial. Fluids are density ordered for all adjacent permeable layers not separated by an impermeable layer.
full.  Fluids are density ordered across the entire reservoir model, regardless of whether there are impermeable layers separating permeable ones.
realisation_number_header_field
 SU header word to store the realisation number. Defaults to mark. Choose wisely
depth_models
 Output traces can be written in depth. (Last block of (Nlayers+1) numbers become depth, not time). Recommended practice is to write them in time, and do trivial time-to-depth conversion slater using deliveryAnalyser.
master_depth_layer_number
 The layer number from which to hang/support all other depths. Must be from 1 to Nlayers. All subsequent depth models will depend on this.
