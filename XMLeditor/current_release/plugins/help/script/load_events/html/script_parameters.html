Event loader Parameters

The parameters for event loading are:

project_path : the name of the project directory where all of the input and output files will be stored (top level for relative pathing)

mincdp : minimum cdp of seismic dataset (for bhpwritecube)

inccdp : cdp increment of seismic dataset (for bhpwritecube)

ncdp : number of cdp of seismic dataset (for bhpwritecube)

minep : minimum ep of seismic dataset (for bhpwritecube)

incep : ep increment of seismic dataset (for bhpwritecube)

nedp : number of ep of seismic dataset (for bhpwritecube)

input_filename : a seismic dataset that corresponds to the horizons to be loaded (project_path/int_datasets/input_filename.dat)

output_filename : output BHPIO indexed horizon dataset name (project_path/int_datasets/output_filename.dat and project_path/int_datasets/output_filename_transpose_cdp.dat)

event1_name : the file name of the 1st event to load (project_path/horizons/event1_name.xyz)

event2_name : the file name of the 2nd event to load (project_path/horizons/event2_name.xyz)

event3_name : the file name of the 3rd event to load (project_path/horizons/event3_name.xyz)

event4_name : the file name of the 4th event to load (project_path/horizons/event4_name.xyz)

event5_name : the file name of the 5th event to load (project_path/horizons/event5_name.xyz)

event6_name : the file name of the 6th event to load (project_path/horizons/event6_name.xyz)

event7_name : the file name of the 7th event to load (project_path/horizons/event7_name.xyz)

event8_name : the file name of the 8th event to load (project_path/horizons/event8_name.xyz)

event9_name : the file name of the 9th event to load (project_path/horizons/event9_name.xyz)

event10_name : the file name of the 10th event to load (project_path/horizons/event10_name.xyz)

event11_name : the file name of the 11th event to load (project_path/horizons/event11_name.xyz)

event12_name : the file name of the 12th event to load (project_path/horizons/event12_name.xyz)
