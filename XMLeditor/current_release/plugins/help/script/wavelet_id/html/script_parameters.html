Wavelet Reservoir ID Parameters

The parameters for Wavelet Reservoir ID are:

first_transform : exponent (base 10) of scale of first wavelet transform scale

inc_transform : exponent (base 10) increment of wavelet transform scales

last_transform : exponent (base 10) of scale of last wavelet transform scale

first_stack_low : first index of the wavelet transform to stack to form the first stack (used to calculate frequency slope)

first_stack_high : last index of the wavelet transform to stack to form the first stack (used to calculate frequency slope)

second_stack_low : first index of the wavelet transform to stack to form the second stack (used to calculate frequency slope)

second_stack_high : last index of the wavelet transform to stack to form the second stack (used to calculate frequency slope)

smooth_length : length of temporal smoother of wavelet transform (in ms)

project_path : the name of the project directory where all of the input and output files will be stored (top level for relative pathing)

output_filename : output BHPIO indexed seismic dataset name (project_path/int_datasets/output_filename_cwt.dat for wavelet transform of first selected dataset, project_path/int_datasets/output_filename_cwtan.dat for normalized frequency slope of second selected dataset)

input_filename : input seismic BHPIO datset name (project_path/int_datasets/input_filename.dat)

tmp : path of temporary directory (must exist).

mincdpsigmaslope : minimum cdp for which to calculate the normalized frequency slope.

maxcdpsigmaslope : maximum cdp for which to calculate the normalized frequency slope.

inccdpsigmaslope : cdp increment for which to calculate the normalized frequency slope.

minepsigmaslope : minimum ep for which to calculate the normalized frequency slope.

maxepsigmaslope : maximum ep for which to calculate the normalized frequency slope.

incepsigmaslope : ep increment for which to calculate the normalized frequency slope.

mincdptransform : minimum cdp for which to calculate the wavelet transform.

maxcdptransform : maximum cdp for which to calculate the wavelet transform.

inccdptransform : cdp increment for which to calculate the wavelet transform.

mineptransform : minimum ep for which to calculate the wavelet transform.

maxeptransform : maximum ep for which to calculate the wavelet transform.

inceptransform : ep increment for which to calculate the wavelet transform.

mincdpmean : minimum cdp for which to calculate the normalization for the frequency slope.

maxcdpmean : maximum cdp for which to calculate the normalization for the frequency slope.

inccdpmean : cdp increment for which to calculate the normalization for the frequency slopem.

minepmean : minimum ep for which to calculate the normalization for the frequency slope.

maxepmean : maximum ep for which to calculate the normalization for the frequency slope.

incepmean : ep increment for which to calculate the normalization for the frequency slope.
