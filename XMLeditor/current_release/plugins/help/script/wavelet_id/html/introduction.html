Introduction to Wavelet Reservoir ID

This program inputs selected data from a BHPIO dataset, indexed by cdp and ep, and takes the wavelet transform of it. It also finds the average frequency slope of the selected dataset (an indicator of sand bed thickness). A different (usually larger) dataset is selected from the BHPIO dataset and the frequency slope of that dataset is calculated and normalized to the average slope of the first selected dataset. The both calculations are distributed, if submitted to a Linux cluster.
