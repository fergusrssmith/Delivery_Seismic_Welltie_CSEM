SEGY loader Parameters

The parameters for SEGY loading are:

mincdp : minimum cdp of seismic dataset (for bhpwritecube)

inccdp : cdp increment of seismic dataset (for bhpwritecube)

ncdp : number of cdp of seismic dataset (for bhpwritecube)

minep : minimum ep of seismic dataset (for bhpwritecube)

incep : ep increment of seismic dataset (for bhpwritecube)

nedp : number of ep of seismic dataset (for bhpwritecube)

project_path : the name of the project directory where all of the input and output files will be stored (top level for relative pathing)

output_filename : output BHPIO indexed seismic dataset name (project_path/int_datasets/output_filename.dat)

input_seismic_filename : an example segy file to use to set up the header block for the BHPIO file (project_path/input_seismic_filename)

input_filenames : name of the ascii file that contains the list of segy files to load. There should be one filename per line. The path for this file and for the segy files should be relative to project_path.

one_for_big_endian : set to 1 if input segy files are big endian, set to 0 if input segy files are little endian
