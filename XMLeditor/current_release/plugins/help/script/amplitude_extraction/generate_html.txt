Introduction to Secant Amplitude Extraction
This program will extract the amplitudes from a seismic unix dataset that has been indexed using BHPIO.  The dataset can be loaded from a set of segy datasets using the utility load_segy.  The input horizons need to be in an ascii format "%14.0f %14.0f %30.4f\n".  The program outputs the extracted amplitudes in both the ascii format, that can be loaded into Landmark, and in a BHPIO formats, that can be viewed in xsecion or map view.  The amplitude that is extracted is the secant amplitude.  In addition one is given the secant area, the width half max, the time of the maximum amplitude, and the times of the two secant points.

html/script_parameters.html
Secant Amplitude Extraction Parameters
The parameters for amplitude extraction are:
<b>project_directory</b> : the name of the project directory where all of the input and output files will be stored (top level for relative pathing)
<b>mincdp</b> : minimum cdp of seismic dataset (for bhpwritecube)
<b>inccdp</b> : cdp increment of seismic dataset (for bhpwritecube)
<b>ncdp</b> : number of cdp of seismic dataset (bhpwritecube)
<b>minep</b> : minimum ep of seismic dataset (for bhpwritecube)
<b>incep</b> : ep increment of seismic dataset (for bhpwritecube)
<b>nedp</b> : number of ep of seismic dataset (for bhpwritecube)
<b>input_filename</b> : input seismic dataset name (project_directory/int_datasets/input_filename.dat)
<b>output_filename</b> : output filename for bhpio format of extracted events (project_directory/int_datasets/output_filename*.dat)
<b>mincdpevent</b> : minimum cdp to start extracting amplitudes
<b>maxcdpevent</b> : maximum cdp to start extracting amplitudes
<b>minepevent</b> : minimum ep to start extracting amplitudes
<b>maxepevent</b> : maximum ep to start extracting amplitudes
<b>picktop</b> : the name of the ascii event that is close to the upper secant point (project_directory/horizons/picktop)
<b>pickbottom</b> : the name of the ascii event that is close to the lower secant point (project_directory/horizons/pickbottom)
<b>shifttop</b> : the amount in ms to shift the picktop before searching
<b>shiftbottom</b> : the amount in ms to shift the pickbottom before searching
<b>afile</b> : the name prefix to output the ascii extracted events (project_directory/horizons/afile.*.xyz)
<b>search</b> : the number of samples, plus and minus, to search around to find the secant point

Secant Amplitude Extraction Job Flow
This job flow requires a seismic dataset (indexed with BHPIO) and ascii events estimating the location of the secant points.  One also needs a file (project_directory/int_datasets/default.dat) with a list of directories where the output BHPIO datasets can be stored.
