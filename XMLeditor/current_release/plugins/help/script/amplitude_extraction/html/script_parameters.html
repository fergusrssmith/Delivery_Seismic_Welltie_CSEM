Secant Amplitude Extraction Parameters

The parameters for amplitude extraction are:

project_directory : the name of the project directory where all of the input and output files will be stored (top level for relative pathing)

mincdp : minimum cdp of seismic dataset (for bhpwritecube)

inccdp : cdp increment of seismic dataset (for bhpwritecube)

ncdp : number of cdp of seismic dataset (bhpwritecube)

minep : minimum ep of seismic dataset (for bhpwritecube)

incep : ep increment of seismic dataset (for bhpwritecube)

nedp : number of ep of seismic dataset (for bhpwritecube)

input_filename : input seismic dataset name (project_directory/int_datasets/input_filename.dat)

output_filename : output filename for bhpio format of extracted events (project_directory/int_datasets/output_filename*.dat)

mincdpevent : minimum cdp to start extracting amplitudes

maxcdpevent : maximum cdp to start extracting amplitudes

minepevent : minimum ep to start extracting amplitudes

maxepevent : maximum ep to start extracting amplitudes

picktop : the name of the ascii event that is close to the upper secant point (project_directory/horizons/picktop)

pickbottom : the name of the ascii event that is close to the lower secant point (project_directory/horizons/pickbottom)

shifttop : the amount in ms to shift the picktop before searching

shiftbottom : the amount in ms to shift the pickbottom before searching

afile : the name prefix to output the ascii extracted events (project_directory/horizons/afile.*.xyz)

search : the number of samples, plus and minus, to search around to find the secant point
